> [!note] Set
> A *set* is a collection of well-defined objects.

>[!note] 
> A set is normally defined in one of two ways:
> - Listing its elements explicitly
> - specifying a property that determines the elements of the set. If $P$ is a good property for elements of some set $S$, then,
> $$\{x\in S:P(x)\}$$

> [!info]- Special Sets
> $\Bbb{N}=\{1,2,3,\cdots\}$
> $\Bbb{Z}=\{\cdots, -2,-1,0,1,2,3,\cdots\}$
> $\Bbb{Q}=\{\frac{p}{q}\mid p\in\mathbb{Z},q\in\mathbb{N}\}$
> $\Bbb{R}$

After this we had done properties of sets like ${\cup,\cap,\in,\phi,}$ Venn diagrams.
>[! Function]
>Let $A$ and $B$ be sets. Then a *function* from $A$ to $B$ is a set $f$ of ordered pairs in $A\times B$ such that for each $a\in A, \exists! b\in B$ with $(a,b)\in f.$
>Domain, Co-domain and Range.

>[! Inverse of a function] 
>$f^{-1}(D)=\{x\in A\mid f(x)\in D\}$
