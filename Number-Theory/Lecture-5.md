 > * $a,b\in X$ then either $[a]=[b]$ **or** $[a]\cap[b]=\phi$
 > * We say $a$ represents the class $[a]=[b]$

## Abstract Algebra (side quest)
### 5.2 The set $\mathbb{Z}/m\mathbb{Z}$
> * under addition is an Abelian group
> * under addition and multiplication is a commutative ring

A $field$ is a ring where you can invert the non-zero elements.

>[!note] $\bar{a}\cdot\bar{b}=1 \iff \gcd(a,b)=1$ (in $\mathbb{Z}/m\mathbb{Z}$)
> $\implies$ By bezout
> $\impliedby$ Using  the fact that $\overline{a\cdot b}=\bar{1}$ so there must exist some $b$

>[!note] $(\mathbb{Z}/m\mathbb{Z})^\times=\{\bar{a}\mid (a,m)=1\}$
>*  is a field.
>* Euler's phi function or the totient function $$\phi(m)\coloneqq \#(\mathbb{Z}/m\mathbb{Z})^\times$$
